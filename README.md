This repository contains BPMN process models for three scenarios, created using **Camunda Modeler**.

## Scenarios

1. **Employee Leave Approval** – Models the workflow of an employee applying for leave, including leave balance verification, manager approval, and notification.
2. **Online Purchase Order Processing** – Models the complete order processing workflow from order placement through payment, shipment, and shipping confirmation.
3. **IT Service Request** – Models the process of handling employee IT support requests, including request registration, severity assessment, assignment, resolution, escalation, and notification.

## Repository Contents

- **Report** – Documentation explaining each BPMN scenario along with screenshots of the process diagrams.
- **Diagrams** – Exported images of the BPMN process models.
- **BPMN Files (.bpmn)** – BPMN 2.0 XML files that can be opened and edited using Camunda Modeler.

## How to View the Models

1. Download or clone this repository.
2. Install **Camunda Modeler**.
3. Open Camunda Modeler.
4. Click **File → Open File**.
5. Select any `.bpmn` file to view or edit the process model.

## Tools Used

- Camunda Modeler
- BPMN 2.0
